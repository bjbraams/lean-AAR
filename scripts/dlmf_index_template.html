DLMF Formalization Index

Which equations of the NIST Digital Library of Mathematical Functions have a formal counterpart in Lean, where it lives, and whether its proof is complete. Each key is a DLMF permalink; each entry is a declaration tagged with Mathlib's @[dlmf] attribute. Statuses come from the compiled axiom audit, not from the source text.

proved proved from admitted lemmas statement only (admitted) definition numbered equation without a tagged declaration

A DLMF key counts once, by its best entry: proved, then proved from admitted lemmas, then statement only, then definition. Within a key, Mathlib comes first, then TauCeti, then lean-AAR. An upstream declaration marked pointer carries no @[dlmf] tag itself; lean-AAR records the correspondence with its checked dlmf_upstream command, which fails to build if the declaration disappears, and the note states how the upstream statement relates to DLMF's. Section totals of numbered equations are shown only where the lean-AAR project has enumerated a DLMF chapter (Chapters 6–9 and 11–14, and the section counts recorded for 13 and 18), against DLMF version 1.2.8; elsewhere only tagged keys are counted. Equation sub-labels such as 13.6.E11_1 count toward their equation.

Generated by scripts/DumpDLMF.lean and scripts/dlmf_index_page.py in lean-AAR; the design is described in DLMFIndex.md there. TauCeti is harvested only through the modules lean-AAR imports; the pinned revision carries no @[dlmf] tags.
